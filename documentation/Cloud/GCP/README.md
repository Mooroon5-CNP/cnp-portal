# GCP

PostgreSQL production can include AWS failover. The common release runbook and
OpenBao checks are in [Platform](../../Platform/README.md).

The initial GKE deployment decisions (D1–D4) and dependency matrix are kept in
[SPEC-CNP-PORTAL-GCP-DEPLOYMENT.md](SPEC-CNP-PORTAL-GCP-DEPLOYMENT.md).
